Aden Express 1.0.2

INSTALL
1. Make a new folder inside Adrenaline's Scripts folder, e.g.  Scripts\1_40 fighter
2. Put AdenExpress.exe into it and start it.
3. Copy the machine code it shows and send it to the seller.
4. Paste the license key you get and press Activate.
   The editor then puts the Adrenaline scripts into the same folder.
5. In Adrenaline run Leveling_1_40.txt (it can open the editor too).

UPDATES
The editor checks for updates when it starts and updates itself.
Your settings (Leveling_1_40.ini) are never overwritten.
